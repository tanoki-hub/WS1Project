# Daily Grind — Coffeehouse recipes

A coffee-shop-inspired recipe website made with HTML, CSS, and browser JavaScript. No Node.js, database server, build step, or package installation is needed.

## Run with VS Code Live Server

1. Open this folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click the top-level `index.html` file and select **Open with Live Server**.

The site starts with popular coffeehouse-style recipes. Use the search box and category filters to find a drink, select **Get the recipe** to see its ingredients and steps, or choose **Add a recipe** to save your own.

New recipes are stored in this browser's local storage, so they remain after refreshes and browser restarts on the same browser and device. They are not synced to other devices or shared with other users.
